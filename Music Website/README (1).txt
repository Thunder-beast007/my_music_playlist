# 🎧 My Music Playlist — Version 2

## New feature: Add Song button

You no longer need to edit `script.js`.

1. Open `index.html`.
2. Tap/click **＋ Add Song**.
3. Select one or more audio files from your phone or PC.
4. The songs appear immediately in the playlist.
5. Tap a song to play it.

You can also remove songs using the ✕ button.

### Important
- Songs are loaded locally in your browser using temporary local URLs.
- The songs are not uploaded to a server by this website.
- If you refresh/close the page, the selected songs will normally disappear and need to be added again.
- Only use music files you have permission to use.
